# Piik Android richkobe — Piik 屏幕共享的 Android 汉化优化版

在手机上**观看**任何 Piik 邀请链接，**从手机发起共享**（本地房间 / 公开邀请 / 自建站点），并带房间聊天。手机上跑的是 Piik 自己的引擎与 web 界面，房间、邀请、密码、画质、观看者管理与桌面端 Piik 完全一致。与 Piik 项目无关联，MIT 许可证。

## 功能特性

**观看与共享**

- 粘贴或从聊天应用分享邀请链接即可观看；播放中离开应用自动切画中画。
- 从手机开房间共享屏幕与声音：本地房间（同 Wi-Fi）、公开邀请（移动数据可用）、连接自建站点三种模式。
- 房间聊天：文字、表情、房间语音（引擎自带，走 WebRTC 数据通道，无需服务器）。

**Android 专属附加**

- **悬浮球**：屏幕边缘可拖拽小球，在游戏或其他 App 里一键开始 / 停止共享、打开主控页；开启状态实时同步到主页面开关。
- **系统声音开关**：可只静音「手机正在播放的声音」，麦克风与房间语音不受影响。
- 主机端返回键直接回应用主页（共享在后台继续）；首启引导忽略电池优化防断流。
- 主页一键复制诊断信息、保存调试日志，真机出问题粘贴即可反馈。

**兼容与汉化**

- 壳层（主页 / 通知 / 提示）全汉化；web 界面用上游内置简体中文包。
- 老设备兼容：所有安装包中的前端语法统一降级（房间页也会发给观看端）；运行时**按实际缺失的接口补齐**，不按 32/64 位或某个内核版本一刀切。已有接口不被替换；加载失败保留中文诊断。
- 手表等小屏布局压缩（按屏幕形态门控，手机零影响）。

## 下载与安装

在 [v2.7.0 Release 页面](https://github.com/yibanm/Piik-android-richkobe/releases/tag/v2.7.0) 下载适合设备的 APK（需允许「安装未知应用」）：

| 文件 | 适用设备 | 大小 |
|---|---|---|
| `Piik-Android-richkobe-v2.7.0-arm64-v8a.apk` | 支持 64 位 ARM 应用的手机、平板或手表 | 28,264,045 字节 |
| `Piik-Android-richkobe-v2.7.0-armeabi-v7a.apk` | 32 位 ARM 系统的老设备 | 29,124,635 字节 |

- **只选一个安装**：多数现代设备选 `arm64-v8a`；32 位 ARM 系统选 `armeabi-v7a`。已有旧版时优先选相同后缀，不能仅凭设备是手表来判断。
- 两包功能相同，均含公开邀请与老系统浏览器兼容处理，系统要求都是 Android 8.0 及以上；v7a 不是精简版，v8a 也不包含 v7a。
- **升级注意**：v2.5.1 起由固定主密钥签名，v2.5.1 及之后可覆盖升级；但 v2.5.0 及之前是 CI 一次性 debug key 签名，**从 v2.5.0 及更早升级到 v2.5.1+ 需先卸载**（一次性代价）。

## 使用方法

1. **观看**：主页粘贴邀请链接点「观看」，或把链接从微信 / QQ 等分享到本应用。
2. **共享**：点「开始共享」→ 允许通知与录音 → 在 Piik 启动器选模式 → 系统选择器里选共享内容 → 切到要共享的应用。停止按钮在通知与主页都有。
3. **悬浮球**：主页开启后，任何界面点球即可开始 / 停止共享。

画质调整、观看者管理、邀请链接在 Piik 主控页内操作，与桌面端相同。

## 与官方安卓版的区别

本仓库保留原生主页、悬浮球、系统声音开关与返回键处理，按 ARM 架构分包。网页界面和内置引擎同步至 Piik v2.7.0；不宣称支持上游仅面向 Windows 或官方 Android 桥的功能。

## 工作原理

```
 WebView (Piik web UI) ──localhost──▶ libpiik.so (Piik Go 引擎，子进程)
                                        │ 启动本地采集进程：
                                        ▼
                                   libpiikcapture.so ──Unix socket──▶ CaptureServer (Kotlin)
                                                                          │
  MediaProjection ▶ VirtualDisplay ▶ GL ▶ 每层一个 MediaCodec H.264 ────── SMED 帧
  系统声音 / 麦克风 ▶ 48 kHz PCM ─────────────────────────────────────────┘
```

- 采集实现 Piik 的 protocol 7 契约（与桌面端采集器同一套），含按层 simulcast 与码率 / 关键帧控制。
- 对引擎的补丁约 40 行：接受 `platform: "android"`、把打开页面交给应用、从应用取局域网地址与 DNS。
- cloudflared 从源码构建（带同样的 DNS 修复），提供公开邀请中继。

## 验证与限制

- v2.7.0 的构建、测试与未验证范围见 [更新日志](CHANGELOG.md#v270)；自动化检查不等于全部真机行为已验证。
- 限制：DRM / 防截屏应用显示黑屏；熄屏时共享暂停；移动数据下多观看者耗上行流量；Android 8 出厂 WebView（Chrome 58–60）不支持 ES Module，会显示诊断页提示更新系统浏览器。
